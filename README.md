# Slack 메시지 정리: 아주 쉬운 사용 설명서

이 프로그램은 Slack에서 **내가 쓴 메시지**를 날짜와 시간으로 골라 지우는 Windows 앱입니다.

## 제일 먼저: 나는 무엇을 해야 하나요?

### 그냥 프로그램을 쓰는 사람

명령어는 필요 없습니다.

1. IT 담당자가 준 `Slack-Message-Cleanup-Setup-*.exe` 파일을 두 번 클릭합니다.
2. 설치가 끝나면 시작 메뉴나 바탕화면의 **Slack 메시지 정리**를 클릭합니다.
3. 아래의 `프로그램에서 메시지 지우기`를 따라 합니다.

### Slack 관리자

처음 한 번만 Slack에 이 앱의 출입증을 등록해야 합니다. 아래의 `Slack에 앱 등록하기`를 따라 합니다.

### IT/개발 담당자

일반 사용자에게 줄 설치 파일을 만듭니다. 아래의 `Setup.exe 만들기`를 따라 합니다.

---

## 프로그램에서 메시지 지우기

1. 프로그램을 엽니다.
2. 관리자가 알려준 **Client ID**를 입력합니다. 숫자와 점으로 된 짧은 글자입니다.
3. **Slack 연결**을 누릅니다.
4. 인터넷 창이 열리면 평소 쓰는 Slack 계정으로 로그인하고 **허용**을 누릅니다.
5. 다시 프로그램으로 돌아와 **대화 목록 불러오기**를 누릅니다.
6. 정리할 채널 또는 DM을 체크합니다.
7. 시작 시각과 끝 시각을 고릅니다. 스레드 답글도 지우려면 **스레드 답글 포함**을 체크합니다.
8. **삭제 대상 미리보기**를 누릅니다. 이때는 아무 메시지도 지워지지 않습니다.
9. 보이는 메시지와 삭제 개수가 맞는지 확인합니다.
10. 확인 상자를 체크하고, 화면에 보이는 삭제 개수를 똑같이 입력합니다.
11. 빨간 **메시지 삭제** 버튼을 누릅니다.

> 삭제는 되돌릴 수 없습니다. 먼저 미리보기를 꼭 확인하세요.

## Slack에 앱 등록하기 (관리자용, 한 번만)

1. [Slack API - Your Apps](https://api.slack.com/apps)를 엽니다.
2. **Create New App**을 누릅니다.
3. **From an app manifest**를 누릅니다.
4. 이 앱을 쓸 회사 Slack 워크스페이스를 고릅니다.
5. 이 저장소의 [slack-app-manifest.json](./slack-app-manifest.json)을 열고, 안의 내용을 전부 복사해 붙여 넣습니다.
6. **Next**와 **Create**를 누릅니다.
7. 새 앱 화면에서 **Install to Workspace**를 누르고 설치를 승인합니다.
8. **Basic Information** 화면에서 **Client ID**를 복사합니다.
9. 복사한 Client ID만 사용자에게 알려줍니다.

### 절대로 주면 안 되는 것

- Client Secret
- OAuth 토큰
- Slack 비밀번호

사용자에게 필요한 것은 Client ID 하나뿐입니다.

## Setup.exe 만들기 (IT/개발 담당자용)

일반 사용자는 이 과정을 할 필요가 없습니다.

1. Windows PC에 [Node.js LTS](https://nodejs.org/)를 설치합니다.
2. 이 저장소 폴더에서 PowerShell을 엽니다.
3. 아래 두 줄을 차례대로 실행합니다.

```powershell
npm.cmd install
npm.cmd run dist:win
```

성공하면 `installer` 폴더에 `Slack-Message-Cleanup-Setup-버전.exe`가 생깁니다. 이 파일 하나를 사용자에게 전달하면 됩니다.

## 안전하게 만든 이유

- 이 앱은 다른 사람이 쓴 메시지를 마음대로 지우지 않습니다.
- Slack에서 원래 삭제할 권한이 없는 메시지는 지워지지 않습니다.
- 삭제 전에 미리보기를 보여 줍니다.
- 확인 상자와 삭제 개수 입력이 모두 맞아야 삭제 버튼이 켜집니다.
- Slack 로그인 정보는 Windows 보안 저장소에 암호화해 그 사용자 PC에만 보관합니다.
- 이 앱은 공개 Slack Marketplace 앱이 아니라 승인받은 사내용 도구입니다.

## 문제가 생기면

| 이런 일이 보이면 | 이렇게 해 보세요 |
| --- | --- |
| Slack 연결이 안 됨 | Client ID가 맞는지, 관리자가 앱을 설치·승인했는지 확인합니다. |
| 대화 목록이 비어 있음 | Slack 앱 권한이 승인됐는지 관리자에게 확인합니다. |
| 어떤 메시지가 안 보임 | 내가 쓴 메시지인지, 날짜 범위가 맞는지, 스레드 포함 설정이 맞는지 확인합니다. |
| 삭제가 실패함 | Slack에서 그 메시지를 직접 삭제할 권한이 있는지 확인합니다. 이미 지운 메시지도 실패로 보일 수 있습니다. |
